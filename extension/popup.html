Rated answers are kept on this device, even when you start a new context window. The fine-tuning export has only satisfactory answers, in OpenAI chat format.
How to use Readie: 1. Press Alt+Shift+C to add the page or PDF you're reading to context (or start a new context window)
2. Press Alt+Shift+R and drag to select part of the screen
3. Ask questions. Readie uses the most relevant parts of every page in context, and the conversation keeps going across tabs until you start a new one.

Note: Your API key is stored locally and only sent directly to OpenAI.
