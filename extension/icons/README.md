# Icons

Please add three PNG icon files here:

- `icon16.png` - 16x16 pixels
- `icon48.png` - 48x48 pixels
- `icon128.png` - 128x128 pixels

You can:
1. Use an online icon generator
2. Create them in design software (Figma, Photoshop, etc.)
3. Use a simple emoji as a placeholder

For now, you can use placeholder icons or the extension will work without them (Chrome will show a default icon).

### Quick Placeholder Option

Use an online service like [favicon.io](https://favicon.io/emoji-favicons/) to generate icons from an emoji (📖 book emoji would be perfect for Readie).
